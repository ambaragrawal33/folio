## Verified artifacts and required topology

Dockerfile.release builds strict static client and compiled non-root Express artifacts. A frozen production install preserves API/shared workspace links; packaged native Argon2 imports without dev dependencies. Health/readiness distinguish liveness from writable replica-set/Redis readiness. Normal development and isolated read-only demo Compose profiles are verified locally. Production startup intentionally fails closed; positive artifact smoke is explicitly NODE_ENV=test.

Required public topology: generated frontend HTTPS origin with same-origin /api proxy to generated API HTTPS origin; WEB_ORIGIN exactly matches the frontend. Preserve httpOnly/Secure/SameSite=Strict refresh cookies and memory-only access tokens. Do not substitute cross-site cookies/permissive CORS for separate free subdomains. Selected proxy must forward Set-Cookie, avoid private API caching, strip untrusted forwarding headers and support narrowly verified Express trusted-proxy configuration. Direct API requests must not spoof client IP/HTTPS. No guessed proxy-hop count is configured before provider selection.

Public demo uses DEMO_MODE=true, folio_demo and folio:demo, with live providers disabled. Store production JWT/refresh/cache encryption keys, Atlas TLS URI and Redis TLS credentials in the chosen secret manager, never VITE_ variables/source/chat. Least-privilege DB/network controls and durable storage are required; loopback Compose configuration is development-only. Normal data and fixtures remain isolated.
