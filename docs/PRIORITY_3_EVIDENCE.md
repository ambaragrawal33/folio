## Implementation and exact contract

Added strict authenticated owned `POST /api/v1/portfolios/:portfolioId/ledger/preview` using the existing transaction input. Snapshot reads and the existing Decimal engine derive identity/automatic/manual historical FX, exact gross/fees and signed native/base cash flows, before/after quantity/remaining costs/average cost, cumulative realized P&L/dividend values and their changes. All financial fields are strings. No current quote or unrealized-market-value prediction is invented. Backdated changes are complete-ledger effects, not falsely described as just this sale's P&L. [Full schema, headers, errors and limits](TRANSACTION_PREVIEW_API.md).

Preview does not create economics, voids, projections, portfolio/user revisions or booking audits. A reserved candidate exists only in memory. Stateless purpose-separated HMAC binds owner/auth version, payload, portfolio revision/sequence, canonical metadata, actual FX and exact effects for three minutes. HTTP append requires that receipt; each Mongo transaction attempt re-resolves/replays/compares before writes, rechecks expiry and retains immutable append/idempotency/ownership behavior. An already-booked same-key/same-body retry returns its original record even after expiry; conflicts reject. Internal trusted fixture/test service calls retain their prior interface; the public route cannot bypass review.

UI now renders actual server review values/provenance, explicit override, full-precision disclosure, pending/unavailable/validation, expired/changed review and explicit revalidation. Revalidation never books or auto-confirms. Uncertain-response retry preserves the original key. Preview receipts are redacted in structured logs. Existing historical FX valuation cache behavior remains; a separate commit-resolution freshness observation rejects stale cached FX for new preview/append. No historical rate is guessed or replaced by today's rate.
