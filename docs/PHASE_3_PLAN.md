Proposed X04 absolute FX convention: let remaining local cost be L, historical base cost B, current local value V and current reference FX f. Effective historical FX h=B/L. Price contribution=(V−L)×h; FX contribution=V×(f−h); their sum is V×f−B. Local return=V/L−1; base return=V×f/B−1; FX return effect=100×(base return−local return) percentage points. Zero-cost bases give unavailable return/decomposition with a reason. Portfolio sums only base money components, never heterogeneous local money/returns. This assigns the price×FX interaction to FX; an alternative decomposition assigns it to price. That allocation is the explicit X04 accounting choice requiring approval.
